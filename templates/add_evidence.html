Acquire & Ingest CCTV Evidence

Upload digital video files, compute SHA-256 cryptographic hashes, and identify hardware vendor
Links this evidence to an established chain of custody case file
Accepts MP4, AVI, DAV (Dahua), MKV, and other standard or proprietary CCTV containers
Auto-detect examines filename conventions and container markers

Forensic Ingestion Workflow

  1. Physical Preservation: The uploaded file is saved bit-exact into evidence/original/ as a read-only master file.
  2. Working Copy: An exact bit-duplicate is created in evidence/working/ for examination.
  3. Cryptographic Baseline: Python hashlib.sha256 computes the 256-bit original hash.
  4. Rule-Based Vendor Heuristic: File naming syntax and container headers are analyzed to classify Hikvision, Dahua, Honeywell, or Unknown/Other.
  5. Audit Logging: Evidence upload and initial hash are logged in SQLite activity_log.
Academic Scope: Supported formats include MP4 and WebM for in-browser playback. Proprietary containers (such as Dahua .dav or raw streams) are preserved intact without transcoding to respect forensic evidence fidelity.
